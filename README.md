# Project Atlas

Modular-monolith foundation and Phase 2 catalog/storefront vertical slice for a premium furniture marketplace. The repository contains infrastructure, identity/session, organizations/RBAC/tenancy, audit/outbox, catalog, moderation, Shopify CSV import, media ingestion, marketplace pages and the Established Lines storefront.

See the [Phase 1 plan](docs/plans/phase-1-foundation.md), [Phase 2 plan](docs/plans/phase-2-catalog-storefront.md), and [local runbook](docs/runbooks/local-development.md).
